# Bypass VMKZ a VMDZ

Este documento desarrolla el paso administrativo del hardware de cifrado desde su estado temprano hacia su estado avanzado.

## Propósito

El bypass VMKZ a VMDZ describe la transición entre:

- el plano temprano de levantamiento raíz/host;
- el plano avanzado delegado/guest;
- la administración del TPM o hardware de cifrado;
- la compatibilidad necesaria para operar bajo un contrato de confianza cero.
