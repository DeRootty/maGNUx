# Laboratorios de investigación maGNUx

> [⬆ Documentación](../README.md) · [🏠 Inicio](../../README.md)

Programa de investigación sobre distribuciones GNU/Linux. El orden de trabajo es Gentoo, Slackware y Arch Linux. La prioridad actual es el laboratorio Gentoo; sus resultados y la metodología que allí se madure permitirán definir las etapas siguientes.

## Referencia inicial

El objeto de estudio fijado para Gentoo es el kernel Linux **6.18.65 LTS**. Su aula de integración toma como referencia documental GCC **16.1.0**. Las versiones y configuraciones efectivas de Slackware y Arch se determinarán cuando se establezcan sus protocolos experimentales.

No se extrapolan resultados de Gentoo a las otras distribuciones ni se presupone que sus mecanismos de configuración sean equivalentes.

> La apertura de una portada no implica que el laboratorio haya iniciado su actividad experimental.
