# Laboratorio IV — LFS: fundamento del kernel Linux

> [⬆ Laboratorios](../README.md) · [Documentación](../../README.md) · [🏠 Inicio](../../../README.md)

## 🚧 En construcción

**Alcance:** Linux From Scratch como referencia para personalización, configuración y compilación del kernel Linux vanilla. No es un aula general de instalación de LFS ni una reproducción completa del libro.

El objetivo es establecer una referencia de partida para comparar la orientación distributiva que se estudia en [Gentoo](../gentoo/README.md), [Slackware](../slackware/README.md) y [Arch Linux](../arch/README.md). Se propone partir de Linux 6.18.65 LTS para facilitar comparaciones, registrando la versión efectiva y compatibilidad de cada entorno.

La referencia de LFS es su [libro oficial](https://www.linuxfromscratch.org/lfs/). Se seleccionarán los capítulos pertinentes para el kernel y los prerrequisitos necesarios, sin confundir la construcción de un sistema LFS completo con el objeto acotado de este laboratorio.

El programa deberá distinguir fuentes vanilla, configuración, dependencias de compilación, kernel y módulos generados, componentes de arranque y pruebas funcionales. El [horizonte tecnológico](../../manifesto/05-horizonte-identidad-temporal.md) fija la finalidad común: fundamentar la orientación distributiva de xGNUpeD en Zalty.

**Estado:** portada habilitada; protocolo y experimentos pendientes. No hay compilaciones acreditadas.
