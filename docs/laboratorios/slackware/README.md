## 🚧 En construcción

**Estado:** portada habilitada; desarrollo experimental pendiente.

Este espacio está reservado al laboratorio II del programa de investigación de maGNUx, dedicado a Slackware.

El objeto común es estudiar cómo se configura, compila e integra Linux orientado a Slackware, respetando su filosofía comunitaria. Las herramientas, versiones, configuraciones y protocolos específicos se definirán con evidencia, sin trasladar automáticamente los procedimientos de Gentoo. Las contribuciones convergerán hacia un único xGNUpeD y la [conmutación distributiva experimental](../../manifesto/05-horizonte-identidad-temporal.md). El [Laboratorio I — Gentoo](../gentoo/README.md) mantiene la prioridad inicial; [LFS](../lfs/README.md) aporta el fundamento del kernel.

Por el momento no se han iniciado experimentos ni se presentan resultados. No se anticiparán conclusiones ni se trasladarán automáticamente los procedimientos de Gentoo.
