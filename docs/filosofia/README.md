# Filosofía

> [⬆ Subir a documentación](../README.md) · [🏠 Inicio](../../README.md)

Esta sección sitúa la relación de maGNUx con Unix/GNU, la metáfora del hormiguero, la materialidad del hardware y la maduración del proyecto.

La filosofía no queda separada de la técnica: funciona como criterio de lectura para entender por qué maGNUx habla de soberanía, nodos, identidad, contrato y comunidad.
