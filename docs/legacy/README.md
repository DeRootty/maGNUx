## Regla de uso

Si un documento histórico se convierte en pieza principal de la nueva lectura, debe moverse o reescribirse dentro de una de las carpetas nuevas.

Si un documento histórico amplía, matiza o conserva una versión larga del razonamiento, debe permanecer enlazado como desarrollo profundo.

La meta no es borrar memoria, sino evitar que el lector tenga que elegir entre dos mapas incompatibles.
