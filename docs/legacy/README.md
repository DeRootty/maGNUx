# Legacy / corpus extendido

> [⬆ Subir a documentación](../README.md) · [🏠 Inicio](../../README.md)

Esta carpeta queda reservada para documentos históricos del repositorio actual que no deban desaparecer, pero que tampoco formen parte de la ruta corta de lectura.

## Uso recomendado

- Mover aquí notas antiguas que sigan teniendo valor.
- Mantener enlaces desde documentos nuevos cuando una nota legacy amplíe un tema.
- Evitar que la raíz del repositorio se llene de documentos sueltos.

## Criterio

```text
La documentación nueva ordena.
La documentación legacy conserva memoria.
```
