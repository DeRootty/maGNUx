# Entrega 06

## Resumen

Esta carpeta contiene una entrega incremental de traducción y estudio del manual **Using the GNU Compiler Collection, for gcc version 16.1.0**.

La entrega 06 conserva las entregas anteriores e inicia la sección **3.4, Options Controlling C Dialect**, centrada en el dialecto C aceptado por GCC. Es una entrega especialmente importante para quien quiera trabajar con **C23**, **GNU23**, compilación de sistemas, código freestanding, cabeceras, kernels, toolchains y proyectos que dependen de diferencias sutiles entre ISO C y extensiones GNU.
