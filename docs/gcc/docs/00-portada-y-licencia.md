**GCC**

## Nota editorial

Esta es una edición técnica en español preparada como base de traducción, estudio y divulgación. Su objetivo es hacer más accesible el manual de GCC a usuarios hispanohablantes de sistemas, programación en C/C++, compilación, toolchains y software libre.

El documento original identifica el manual como **Using the GNU Compiler Collection**, para **gcc version 16.1.0**. Documenta el uso de los compiladores GNU y sus opciones.
