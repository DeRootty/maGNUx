# Zalty develop

Espacio de desarrollo experimental para Zalty OS dentro del repositorio maGNUx.

Este directorio queda reservado para prototipos, pruebas de implementacion y piezas iniciales antes de consolidarlas en ramas documentales o componentes estables.

## Proposito inicial

- desarrollar el puente entre nodos tecnicos y nodos semioticos;
- preparar prototipos relacionados con `/boot/metal/`;
- experimentar con initramfs, inventario tecnico y comprobacion semantica;
- separar trabajo en curso de la documentacion conceptual estable.

## Estado

Experimental.
