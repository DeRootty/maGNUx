# dev nodes

Semiótica inicial de `/dev` para Zalty OS.

Este directorio contendrá nodos semióticos que describen el significado, legitimidad y política de nodos técnicos creados bajo `/dev`.

Primeros objetivos:

- declarar nodos esenciales como `/dev/null`, `/dev/zero`, `/dev/random`, `/dev/urandom`, `/dev/console` y `/dev/kmsg`;
- declarar nodos de almacenamiento estables mediante UUID/PARTUUID;
- distinguir nodos ordinarios, críticos y de alta autoridad.
