# Initramfs de Zalty

> [⬆ Subir a Zalty](../readme.md) · [🏠 Inicio](../../README.md)

Esta carpeta concentra los prototipos de arranque temprano de Zalty.

## Función

El initramfs es el primer laboratorio práctico de maGNUx porque permite ejecutar lógica de identidad, contrato y validación antes de entregar el control al sistema raíz.

## Prototipos disponibles

| Prototipo | Estado | Función |
|---|---|---|
| [prototipo-hostid-v0.1](prototipo-hostid-v0.1/README.md) | Experimental | Validación temprana de identidad de host, política de arranque y comunicación inicial. |

Consulta [Fases de implementación](../fases/readme.md) para entender cómo este laboratorio encaja con `/boot/metal`, `/run/maGNUx` y `/upLoad`.
