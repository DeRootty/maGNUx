## Navegación recomendada dentro de cada bloque

Cada archivo de este directorio debería comenzar y terminar con:

```md
> [⬆ Subir al índice CONFIG_*](README.md) · [🏠 Inicio](../README.md)
```

Actualmente algunos bloques usan solo:

```md
```

Eso permite volver al documento padre, pero no ofrece acceso directo al inicio del repositorio. La corrección segura recomendada es sustituirlo por:

```md
> [⬆ Subir al índice CONFIG_*](README.md) · [🏠 Inicio](../README.md)
```

## Nota sobre nombres de archivo

Este directorio conserva los nombres actualmente existentes. Hay una mezcla de estilos:

```text
config_a.md
CONFIG-F.md
```

GitHub distingue mayúsculas y minúsculas, por lo que una normalización futura debería hacerse en una rama separada y con revisión manual.
